# CW Runner 设计文档

## 1. 项目概述

### 1.1 产品定位
CW Runner 是一款面向业余无线电爱好者及 CW 学习者的微信小程序，提供等幅电报（Continuous Wave）的模拟发报与异步听抄练习功能。

### 1.2 核心设计原则
- **匿名性**：云端列表不展示发送者身份，规避 UGC 内容审核风险
- **异步性**：非实时通信，用户随时上传、随时播放
- **拟真性**：虚拟自动键手感贴近真实 Paddle，音频合成还原 CW 听觉体验
- **可调速**：WPM（Words Per Minute）5-40 可调，发报与播放均按实际 WPM 计算时长

## 3. 模块设计

### 3.1 输入模块（Paddle）

#### 3.1.1 界面布局
- **屏幕上半区**：实时显示当前输入的原始时序文本（如 `.-/-.../.-.`）
- **时序区底部**：WPM 调节滑块（5-40 WPM）
- **屏幕下半区**：左右双按钮（左 dit / 右 dah）

#### 3.1.2 交互逻辑

| 操作 | 行为 | 时序记录 |
|------|------|----------|
| 点下左桨 | 发点，若按住则自动连续发点 | 追加 `.` |
| 点下右桨 | 发划，若按住则自动连续发划 | 追加 `-` |
| 左右同时按 | 优先后发（iambic 模式） | 按实际输出记录 |
| 松手后 > 3 点长 | 字母间隔 | 追加 `/` |
| 松手后 > 7 点长 | 单词间隔 | 追加 `\|` |

#### 3.1.3 自动键时序参数（20 WPM 基准）

```
点长 (unit) = 1200 / WPM ms
            = 60ms  @ 20 WPM
划长 (dash) = 3 * unit
点划间隔 (intra-char gap) = 1 * unit
字母间隔 (inter-char gap) = 3 * unit
单词间隔 (inter-word gap) = 7 * unit
```

> WPM 与 unitMs 关系：标准 PARIS 参考词。WPM 越大，unitMs 越小，发报越快。
> - 5 WPM  → unitMs = 240ms
> - 20 WPM → unitMs = 60ms（设计基准）
> - 40 WPM → unitMs = 30ms

#### 3.1.4 Iambic 模式
当左右两桨同时按下时，采用 Iambic B 模式：
1. 若当前正在发点，则下一周期发划
2. 若当前正在发划，则下一周期发点
3. 两桨均松开时，完成当前周期后停止

#### 3.1.5 状态机

```
[空闲] --按下左桨--> [发点中]
[空闲] --按下右桨--> [发划中]
[发点中] --松开左桨--> [等待间隔]
[发划中] --松开右桨--> [等待间隔]
[等待间隔] --超时3点长--> [追加/] --> [空闲]
[等待间隔] --超时7点长--> [追加|] --> [空闲]
[等待间隔] --按下任一键--> [发点中/发划中]
```

### 3.2 音频模块（Web Audio）

#### 3.2.1 架构
使用微信小程序内置的 Web Audio API 进行本地音频合成。

#### 3.2.2 音频图

```
+----------+    +----------+    +----------+    +----------+
|Oscillator|--->| GainNode |--->| GainNode |--->|AudioDestination|
| (600Hz)  |    |(Envelope)|    | (Volume) |    |  (扬声器)      |
+----------+    +----------+    +----------+    +----------+
```

#### 3.2.3 包络设计
采用快速 Attack / Decay 避免爆音：
- Attack: 5ms
- Decay: 5ms
- Sustain: 目标音量
- Release: 5ms

#### 3.2.4 播放解析规则（按实际 WPM）

遍历 `code` 字符串，按以下规则生成音频事件。所有时长按 `speedRatio = 20 / wpm` 比例缩放：

| 字符 | 行为 |
|------|------|
| `.` | 播放 unitMs 音 + unitMs 静音 |
| `-` | 播放 3*unitMs 音 + unitMs 静音 |
| `/` | 追加 2*unitMs 静音（总间隔 3*unitMs） |
| `\|` | 追加 6*unitMs 静音（总间隔 7*unitMs） |

### 3.3 云端模块

#### 3.3.1 数据模型

```json
{
  "_id": "云数据库自动生成的ID",
  "code": "-.-./--.-",
  "wpm": 20,
  "timestamp": 1713862800,
  "sender": "openid_xxx"
}
```

#### 3.3.2 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | String | 原始时序文本，仅包含 `.` `-` `/` `\|` |
| `wpm` | Number | 发报速度（Words Per Minute），播放端据此计算时长 |
| `timestamp` | Number | 创建时间 Unix 时间戳 |
| `sender` | String | 发送者匿名标识（openid 前 16 位） |

#### 3.3.3 云函数接口

**uploadCW**
- 参数：`{ code: string, wpm: number }`
- 校验：
  - code 不能为空，长度 <= 500
  - code 仅允许字符 `.` `-` `/` `\|`
  - wpm 必须在 5-60 之间
  - 频率限制：单用户每小时最多 50 条
- 逻辑：获取 openid → 生成匿名 sender → 写入云数据库
- 返回：`{ success: true, id: string }`

**getCWList**
- 参数：`{ limit?: number, offset?: number }`
- 校验：limit 1-50，offset >= 0
- 逻辑：按 `timestamp` 倒序查询，分页返回
- 返回：`{ success: true, list: Array }`（不含 sender 字段）

**getOpenid**
- 无参数
- 返回：`{ openid: string }`

#### 3.3.4 匿名策略
- 服务端存储 `sender` 字段用于去重或反垃圾，但绝不返回给客户端
- 客户端列表仅展示 `code`、`wpm`、`timestamp`
- 用户无法知道某条 CW 是谁发的

### 3.4 本地调试模式

#### 3.4.1 开关控制
通过 `miniprogram/utils/config.js` 中的 `DEBUG_MODE` 常量控制：

```javascript
const DEBUG_MODE = false  // true: 本地调试，false: 云端模式
```

#### 3.4.2 调试模式行为

| 功能 | DEBUG_MODE=true | DEBUG_MODE=false |
|------|-----------------|------------------|
| 云开发初始化 | 跳过 | 正常初始化 |
| 获取 openid | 跳过 | 调用 getOpenid 云函数 |
| 上传 CW | 写入本地 Mock 数组 | 调用 uploadCW 云函数 |
| 获取列表 | 返回 Mock 数据 | 调用 getCWList 云函数 |
| 页面提示 | 显示"本地调试模式"红色横幅 | 无 |

#### 3.4.3 Mock 数据
调试模式内置 3 条示例数据，上传的新数据也会追加到 Mock 数组中（最多保留 20 条）。

### 4.2 交互流程

#### 4.2.1 发报流程

```
用户按下左/右桨
       |
       v
本地 Web Audio 实时播放 600Hz 音（按当前 WPM 速度）
       |
       v
记录时序文本 (. / -)
       |
       v
松手后根据间隔自动追加 / 或 |
       |
       v
调节 WPM（可选，默认 20）
       |
       v
点击 [保存] 按钮
       |
       v
调用 uploadCW（云端/Mock）
       |
       v
列表自动刷新
```

#### 4.2.2 收报/听抄流程

```
用户浏览模拟报文列表
       |
       v
点击某条记录的 [播放] 按钮
       |
       v
本地 Web Audio 按 code + wpm 解析播放
       |
       v
用户听抄，对照时序文本
```

## 6. 技术选型

- 微信小程序原生框架

### 6.2 后端
- 微信云开发（CloudBase）

### 6.3 开发环境

- 本地调试模式支持无云环境开发

## 7. 安全与合规

### 7.1 UGC 风险规避
- 云端列表仅展示 CW 时序文本（`.` `-` `/` `\|`），不包含任何自然语言
- 不展示发送者身份，无法建立社交关系
- 无评论、点赞、私信等社交功能

### 7.2 内容过滤
- 云函数端校验 code 字段，仅允许合法字符
- 长度限制：最大 500 字符
- 频率限制：单用户每小时最多 50 条
